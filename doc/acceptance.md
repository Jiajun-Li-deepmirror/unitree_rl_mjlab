# 验收标准（草案，2026-11-10）

六个机型（Go2、As2、B2、Go2-W、As2-W、B2-W）的盲走策略和深度学生共用一份标准。只在物理上确实不同的地方按机型区分：
负载上限、腿式 / 轮式各自的项目。其余门槛对所有机型一样。标【待定】的条目等用户确认；确认后写进代码
（`scripts/blind/acceptance/accept_tables.py`、`tools/go2_depth/acceptance/`），这一轮剩下的检查和干净复现都按它判。

## 1. 通过的定义

- 一个模型通过 = mjlab 验收 3 个随机种子（0 / 1 / 2）全部通过 + tinynav 验收通过。
- 运气通过【待定，建议】：某个种子只因 1 台（256 台中）摔倒而不过，且查得到是极端随机组合（载荷 / 重心 / 摩擦 / 增益
  落在随机范围的边缘），而另外两个种子同一项全过，记为通过并在报告里写明。现在靠人判断，改为按这条规则自动判。

## 2. mjlab 验收（每个种子）

指令一律按 2 m/s²（vx、vy 合起来）和 3 rad/s² 斜坡给，同真机控制器和 tinynav-sim（2026-11-10 起全部机型）。

| 项目 | 内容 | 门槛 | 现状 → 建议 |
|---|---|---|---|
| 平地速度 | 44 条指令（前后、横移、斜向、转弯、弧线），每条 32 台 | 实际 / 指令在 80–120%，0 摔 | 统一，不变 |
| 跑偏 | 直行和横移 10 s，256 台 | 航向偏差中位数 ≤ 3°、p10 / p90 ≤ 8°；横向偏移 p10 / p90 ≤ 行进距离的 5% | B2-W 横移 5.2% → **统一 5%**【待定】 |
| 原地旋转 | ±0.5 / 1.0 / 1.5 rad/s | 终点离起点中位数 ≤ 0.2 m | 统一，不变 |
| 交替原地转 | 左右交替 8 次再站 2 s | 终点离起点中位数 ≤ 门槛，0 摔 | 现在每台不同（B2 0.17、Go2 0.25、Go2-W 0.29、As2 0.30、As2-W 0.31、B2-W 0.28 m，取当时已部署盲走的最差值）→【待定】 |
| 负重站立 | 负载上限下站立，3 s 后 | 0 摔 | 统一，不变 |
| 停车 | 各方向松杆停车 | 站稳离地 ≤ 1%，停后 4 s 蠕动 ≤ 1 cm，1.0 m/s 刹停距离 ≤ 30 cm | 统一，不变 |
| 原地踏步 | 踏步复位 | 踏步时抬脚、2 s 内复位、漂移 ≤ 5 cm、0 摔 | 统一，不变 |
| 步态节奏 | 速度时钟 | 判定的指令全部合拍 | 统一，不变 |
| 楼梯 | 5–18 cm 各档上下楼 | 有操作员 ≥ 95%、无操作员 ≥ 90%、上下楼速度 0.8–1.2 倍、停稳 ≥ 95%、停住四脚着地 ≥ 90% | 统一，不变 |
| 四轮着地（轮式） | 前进后退 | ≥ 98%，0 摔 | 统一，不变 |
| 摔倒 | 平地、楼梯、跑偏、停车 | 0 | 统一，不变 |
| 负载停车站姿 | 负载上限、1.5 m/s 急停后站 3 s | 腿关节偏离默认站姿 p90 ≤ 0.15 rad（同真机踏步复位的触发线） | 只记录 →【待定】是否考核 |
| 髋负载 | 站立 / 1 m/s 时髋力矩 | 不考核 | 不变 |
