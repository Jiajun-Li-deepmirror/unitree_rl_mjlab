# 机器人物理参数的来源

2026-11-11，用户定的规则：「机器参数从 unitree_ros 里面获取……先和 unitree ros 对齐，没有的参数再和官网对齐」。

## 怎么选模型

- `BLIND_PARAMS` 里写 `model=uros`，就用对齐后的模型（`src/assets/robots/uros.py`）；不写就是原来的模型。
- `src/robot_table.py` 里六个机型都写了 `model=uros`，配方（`jobs/recipes/unified.py`）从这张表取值，所以新训练都用对齐模型。
- 每次训练的 `run_env.sh` 和盲走包的 `blind_params.txt` 都记了这个值。已交付的模型和旧检查点没有这个值，评估和导出仍用原来的模型，可以复现。
- 对齐模型的文件是 `xmls/<机型>_uros.xml`，由 `tools/robot_params/align_uros.py` 从 `unitree_<机型>/uros/` 里存的 URDF（unitree_ros 提交 725b59b）生成，不要手改。

## 和 unitree_ros 对齐的内容

| 机型 | 质量（原 → 对齐） | 其他 |
|---|---|---|
| Go2 | 15.21 → 16.09 kg（加上 12 个电机转子；小腿 0.241 → 0.194） | 力矩上限 23.7 / 23.7 / 45.43（原 23.5 / 23.5 / 45） |
| Go2W | 19.13 → 19.52 kg（轮电机算在小腿上：小腿 0.24 → 0.80，轮 0.98 → 0.52） | 小腿力矩 35.55（原 45），轮力矩 23.7（原 15） |
| As2 | 20.70 → 17.64 kg（机身 11.18 → 8.8） | 腿关节阻尼 0.2 / 0.2 / 0.5，摩擦 1 / 1 / 2 N·m（宇树 as2.xml） |
| As2W | 26.0 kg（不变） | 腿关节阻尼和摩擦同 As2（腿相同，As2W 的 URDF 没给） |
| B2 | 74.58 kg（不变） | 小腿力矩 320（原 300） |
| B2W | 82.42 kg（不变） | 小腿力矩 320（原 300），轮力矩 20（原 40；官网写 40，按规则取 URDF） |

运动学、关节限位、足端和轮子半径六个机型原来就和 URDF 一致，没改。

## unitree_ros 没有、按官网补的

- 负载（www.unitree.com 产品页，行走负载）：
  - As2 15 kg、As2W 16 kg（原来是 10 / 13，按「约一半体重」定的）。
  - Go2 / Go2W 写的是约 8 kg、极限约 12 kg，仍按 12 kg 训练和验收。
  - B2 / B2W 写的是 40 kg 以上，仍按 40 kg。

## 两边都没有的参数（保持现状）

- **减速比、转子惯量（armature）**：As2 用的是宇树 as2.xml 的值，其他机型的来源不明。
- **关节摩擦和阻尼**：只有 As2 有数据，其他机型是 0，也没做随机化。
- **电机力矩-转速曲线**：URDF 只给了最高转速（如 Go2 30 / 30 / 16 rad/s），没有曲线，所以没建模。
- **足端和地面的摩擦系数、轮胎变形**。
- **真机的 kp / kd**：unitree_ros 里只有 Gazebo 用的 PID；官网只在 Go2 例程里给了站立 kp 40 / kd 1。
- **质量和官网对不上的**：B2 的 URDF 是 74.6 kg，官网写约 60 kg；As2 的 URDF 是 17.6 kg，官网写约 20 kg。按规则以 URDF 为准。
- **相机和雷达的安装位置**：用的是我们自己的 navcore CAD。
